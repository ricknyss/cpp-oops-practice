# 🚀 C++ Object-Oriented Programming (OOP) Practice

Welcome to my **C++ Object-Oriented Programming (OOP) Practice Repository**.

This repository contains my practice programs while learning **Object-Oriented Programming in C++**. Each program focuses on a specific OOP concept and demonstrates how it works using simple and understandable examples.

---

# 📚 Topics Covered

## 1. Classes and Objects

A **class** is a blueprint used to create objects. It defines the data members (variables) and member functions (methods) that an object will have.

An **object** is an instance of a class that can access its data and functions.

### Concepts

* Class Declaration
* Object Creation
* Member Variables
* Member Functions
* Access Specifiers
* Constructors
* Destructors

---

## 2. Encapsulation

Encapsulation is the process of combining data and functions into a single unit (class) while restricting direct access to the data.

### Benefits

* Data Security
* Better Code Organization
* Controlled Access
* Easy Maintenance

### Access Specifiers

* `private`
* `protected`
* `public`

---

## 3. Inheritance

Inheritance allows one class to acquire the properties and behaviors of another class.

### Advantages

* Code Reusability
* Easy Maintenance
* Extensibility
* Hierarchical Design

### Types of Inheritance

* Single Inheritance
* Multiple Inheritance
* Multilevel Inheritance
* Hierarchical Inheritance
* Hybrid Inheritance

---

## 4. Polymorphism

Polymorphism means **"Many Forms."** It allows the same function or operator to behave differently depending on the context.

### Compile-Time Polymorphism

* Function Overloading
* Operator Overloading

### Run-Time Polymorphism

* Function Overriding
* Virtual Functions

---

## 5. Operator Overloading

Operator overloading allows existing operators to work with user-defined objects.

### Examples

* `+`
* `-`
* `*`
* `==`
* `<`
* `<<`
* `>>`

---

## 6. Runtime Polymorphism

Runtime polymorphism is achieved using:

* Inheritance
* Virtual Functions
* Base Class Pointer

It enables dynamic method dispatch where the function to execute is determined at runtime.

---

## 7. Abstraction

Abstraction hides implementation details and exposes only the essential functionality.

In C++, abstraction can be implemented using:

* Abstract Classes
* Pure Virtual Functions
* Interfaces

### Benefits

* Reduced Complexity
* Improved Security
* Better Code Design
* Easier Maintenance
